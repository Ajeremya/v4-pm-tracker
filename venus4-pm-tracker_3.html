Connect Firebase Sync
One-time setup — takes ~5 minutes
1
Go to console.firebase.google.com → Add project → name it v4-tracker → disable Google Analytics → Create project
2
In your project → click Realtime Database (left sidebar) → Create database → choose any location → start in Test mode → Enable
3
Go to Project Settings (gear icon) → Your apps → click </> Web → register app as v4-tracker → copy the firebaseConfig values
4
Paste each value below, then click Save & Connect
apiKey
authDomain
projectId
storageBucket
messagingSenderId
appId
databaseURL (find in Realtime Database page)
Venus4 NPI / PM Tracker
